# The archived story

Archived 2026-11-14 (Karl: the game is Survival and Creative now; docs/sandbox/SURVIVAL.md). These were the storyline and
the story engine's docs. The code (`Source/Story`, the `Game/GameStory*.cs` files) and the data (`Story/`) stay in place;
`Game.StoryOn` is false, so nothing of it runs in play.

- To try it again for one run: add `--story` to the command line.
- To bring it back for good: set `Game.StoryOn` to true (GameStory.cs), move these files back to `docs/story`, and point the
  references at them again.

Files: STORYLINE.md (the story as it stood), STORY.md (the engine), FRAGMENTS.md (the five records and their data
centres), BREAKOUT.md, OBJECTIVES.md, OUTPOSTS.md, PATHS.md, and `starts/` (the placeholder Castaway start and its opening).
