# Archive

Documents for modes that are no longer worked on: Zombies, Co-op and the arena modes. The code they describe is still in the game, but nothing new is built on it.

Agents: don't read these unless the user asks for a fix in an archived mode.

- `ZOMBIES-MODE.md`: the Zombies mode's rules, rounds, economy and zombie types.
- `PVE-DESIGN.md`: the Co-op mode's design.
- `SCORE-SCALING.md`: arena score limits by player count.

Still live, and moved out of `docs/zombies/` on 2026-11-11: `docs/sandbox/WEAPON-BUILDER.md` (Sandbox guns use the weapon builder) and `docs/sandbox/MASS-HORDE.md` (the crowd system, which Sandbox hordes use).
