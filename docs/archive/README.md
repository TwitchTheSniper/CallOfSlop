# Archive

Documents for modes that are no longer worked on: Zombies, Co-op and the arena modes. The code they describe is still in the game, but nothing new is built on it.

Agents: don't read these unless the user asks for a fix in an archived mode.

- `ZOMBIES-MODE.md`: the Zombies mode's rules, rounds, economy and zombie types.
- `PVE-DESIGN.md`: the Co-op mode's design.
- `SCORE-SCALING.md`: arena score limits by player count.
- `MANUAL-ARENA.md`: the player manual's sections on matches, game modes, loadouts, perks, kill streaks, bots, progression, Zombies and Co-op (from docs/MANUAL.md), and, at its end, the old text of the mixed sections rewritten for Sandbox on 2026-11-11: Pre-match lobby, Lobby size, Map select, Maps (the arena map lists), Grenades and equipment, Music (kill frenzy).
- `README-ARENA.md`: README.md's old "Testing without playing" (every self-test section described) and "How it works" (arena netcode, arms, legs, the old project layout and command lines), as they were before the 2026-11-11 rewrite.
- `MODES-README.md`: the example arena module from Source/Game/Modes/README.md.
- `WEAPON-BUILDER-ZOMBIES.md`: the weapon builder's Zombies economy: the run loop, run progression, extra weapon slots, the push cart (from docs/sandbox/WEAPON-BUILDER.md).

Still live, and moved out of `docs/zombies/` on 2026-11-11: `docs/sandbox/WEAPON-BUILDER.md` (Sandbox guns use the weapon builder) and `docs/sandbox/MASS-HORDE.md` (the crowd system, which Sandbox hordes use).
