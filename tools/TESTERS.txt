CALL OF SLOP - tester build
===========================

Thanks for testing!

Running it
- Unzip the whole folder anywhere (don't run it from inside the zip).
- Double-click CallOfSlop.exe. No install needed; .NET is included.
- Windows 10/11, 64-bit, with a graphics card that supports OpenGL 4.1.
- If Windows SmartScreen warns about an unknown app, click "More info" > "Run anyway".

Playing together
- Everyone must use the SAME build (the same zip). Different builds can't join each other.
- One person hosts from the Multiplayer screen; others join from the server browser or by address.
  The host may need to allow the game through the Windows firewall when asked.
- Single player against bots works offline.

Your saves
- Your progress carries over to new builds automatically: settings, progression, loadouts and
  workbench builds are saved in %APPDATA%\CallOfSlop (paste that into Explorer's address bar, or use
  Settings > Player > Open save folder). Just unzip the new build anywhere and play.
- Coming from an older build that kept them in its own folder: the first time you start this build it
  copies them over for you (from this folder, or from your previous build if it's unzipped next to this
  one). Your old files are left untouched. If your level didn't come over, copy progress.txt,
  loadout.txt and settings.txt from the old build's folder into %APPDATA%\CallOfSlop yourself.
- Want the saves to stay in this folder instead (e.g. on a USB stick)? Put an empty file called
  portable.txt next to CallOfSlop.exe.

Reporting bugs
- Say what you were doing, which map and mode, and attach callofslop.log from this game folder
  (it's written fresh each time the game starts, so grab it before restarting).
- Screenshots help a lot.
